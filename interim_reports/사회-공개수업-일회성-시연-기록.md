# 사회 공개수업 과정안·시연 자료 기록

이 문서는 앱 개발과 분리한 **1회성 사회 공개수업 기록**이다. 수업 맥락, 예시 글과 질문, 당시의 시연 구성만 문서로 보존한다. 모든 예시는 **수업 시연용 가상 자료**이며 실제 학생 활동 결과가 아니다.

작성·정리일: 2026-10-26

## 1. 수업 맥락

- 대상: 초등학교 5학년
- 범위: 사회 교과서 95~97쪽, 조선 후기 경제 변화와 신분제 변화
- 탐구 질문: **농사와 장사의 변화는 사람들의 생활과 신분을 어떻게 바꾸었을까?**
- 학습 목표: 조선 후기 농업과 상업의 변화가 신분제 변화에 미친 영향을 자료를 근거로 설명할 수 있다.
- 활동 흐름: 협동 활동에서 역할별 자료 공유 → 개인 설명 글 1장 작성 → 친구 글에 질문 1개 남기기 → 발표에서 자료를 근거로 답변하고 설명 보완하기
- 평가·표시 원칙: 질문의 좋고 나쁨이나 선택의 정오를 점수로 표시하지 않는다.

## 2. 담벼락 수업 구성

- 수업용 제목: **농사와 장사의 변화, 신분을 흔들다**
- 발표 주제: **경제 변화와 신분제 변화는 어떻게 이어졌을까?**
- 핵심 낱말: **모내기법, 상품 작물, 장시, 보부상, 재산, 상민, 양반, 신분제**
- 학생별 포스트잇: 1장
- 학생별 질문: 최소 목표 1개·최대 1개
- 참여자: 실제 학생 정보 없이 색 닉네임을 사용한 가상 참여자 4명

작성 발문:

> 경제 변화가 신분제 변화로 어떻게 이어졌나요? 교과서에서 찾은 근거를 넣어 써 봅시다.

질문 발문:

> 친구 글에서 변화가 이어지는 이유나 근거가 궁금한 부분을 물어봅시다.

## 3. 예시 글·질문·답변·이어지는 질문

### 예시 1 — 재산과 신분의 차이 / 하늘

**포스트잇**

농사와 장사로 재산을 모은 일부 상민은 양반이 되려고 했습니다. 돈이 많아져도 신분에 따른 차별은 남아 있었기 때문입니다.

**친구의 익명 질문**

돈이 있어도 왜 양반이 되려고 했나요?

**작성자의 답변**

상민으로 차별받지 않고 양반의 혜택을 누리고 싶었기 때문입니다. 교과서 97쪽에서 근거를 찾았습니다.

**발표 뒤 질문 이어가기**

재산을 모은 상민은 어떤 방법으로 양반이 되려고 했을까요?

### 예시 2 — 경제 변화의 연결 / 초록

**포스트잇**

모내기법이 퍼지고 팔기 위한 작물을 기르면서 농산물을 사고파는 일이 많아졌습니다. 이 과정에서 재산을 모은 사람도 나타났습니다.

**친구의 익명 질문**

농사의 변화가 장사와 어떻게 연결되나요?

**작성자의 답변**

농산물을 더 많이 거두거나 팔기 위해 기르면 시장에서 거래할 물건이 늘어납니다. 교과서 95~96쪽의 농업과 장시 자료를 연결했습니다.

**발표 뒤 질문 이어가기**

장시가 늘어나면서 보부상의 활동도 많아진 까닭은 무엇일까요?

### 예시 3 — 일부와 모두 구별하기 / 노랑

**포스트잇**

조선 후기에는 농업과 상업이 발달해 잘사는 사람이 나타났습니다. 하지만 모든 농민이 부자가 된 것은 아닙니다.

**친구의 익명 질문**

모든 농민이 부자가 된 것은 아니라는 근거는 무엇인가요?

**작성자의 답변**

교과서 95쪽에는 잘사는 농민이 ‘나타나기도 했다’고 나옵니다. 그래서 일부 사람의 변화라고 생각했습니다.

**발표 뒤 질문 이어가기**

가난한 양반의 자료까지 함께 보면 재산과 신분의 관계를 어떻게 설명할 수 있을까요?

### 예시 4 — 신분제의 동요 이해하기 / 보라

**포스트잇**

재산을 모은 일부 상민이 양반이 되려고 하면서 신분제가 흔들렸습니다. 그렇다고 신분제가 완전히 없어진 것은 아닙니다.

**친구의 익명 질문**

신분제가 ‘흔들렸다’는 것은 무슨 뜻인가요?

**작성자의 답변**

상민이 양반이 되는 등 원래의 신분 구분에 변화가 생겼다는 뜻입니다. 모든 사람의 신분 차이가 없어진 것은 아닙니다.

**발표 뒤 질문 이어가기**

양반이 늘어나면 기존의 신분 질서에는 어떤 변화가 생길까요?

교과서 쪽수와 예시 3의 문구는 사용자가 제공한 자료를 그대로 반영했다.

## 4. 당시 확인한 앱 기능과 시연 방법

- 글·질문·답글·이어지는 질문은 항목당 80자 이내로 작성했다.
- 답글 입력은 질문 단계에서 지원됐다. 작성자의 답변을 이 단계에서 등록한 뒤 발표에서 보여 주는 방식으로 구성했다.
- 발표 스포트라이트의 기존 `답글 1개` 버튼을 눌러 답글을 펼쳐 보였다.
- 질문 이어가기는 발표 단계에서 교사가 열었다. 원래 질문 작성자가 자신의 질문 아래에 새 궁금증을 한 번 이어 썼으며, 담벼락 목록에서 표시됐다.
- 고정 색 이름은 하늘 → 하늘 파랑, 초록 → 숲 초록, 노랑 → 해바라기 노랑, 보라 → 포도 보라로 대응했다.
- 당시 생성 화면은 핵심 낱말을 최대 5개 지원해 모내기법·상품 작물·장시·상민·신분제를 입력했다. 수업의 핵심 낱말 8개 전체는 이 문서에 보존한다.
- 출석 번호와 교사 전용 정보는 캡처에 표시하지 않았다. 새 제품 기능은 개발하거나 배포하지 않았다.

## 5. 과정안용 캡처 구성 기록

| 장면 | 구성 |
|---|---|
| 익명 질문 | 네 포스트잇을 같은 노란색으로 표시하고 작성자의 색 이름을 숨겨 글과 질문에 집중하게 함. |
| 색 공개·발표 스포트라이트 | 예시 1의 하늘 파랑 글과 익명 질문을 크게 보여 주고 기존 답글 버튼으로 작성자 답변을 펼침. |
| 질문 이어가기 | 예시 1·2의 원래 질문 아래 답글과 새롭게 궁금해진 점을 표시함. |

이미지 상단의 제목·발문·수업 정보·가상자료 표시는 앱 밖의 과정안용 캡션으로 구분했다. 축소 삽입 시 읽을 수 있도록 글자 크기와 두 열 배치를 조정했다. 캡처 이미지 자체는 이번 정리에서 삭제한다.

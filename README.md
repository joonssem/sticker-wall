# 스티커 담벼락

생각을 포스트잇으로 붙이고, 궁금한 글에 익명 질문을 남기는 실시간 교실 활동 웹앱입니다. 학생은 출석 번호와 색 닉네임으로 참여하고, 교사는 담벼락의 진행 단계·발표 순서·색 공개를 제어합니다.

- 서비스: <https://joonssem.github.io/sticker-wall/>
- 17명 테스트 장면: <https://joonssem.github.io/sticker-wall/?test=17>

## 활동 흐름

1. 교사가 Firebase 이메일/비밀번호 계정으로 로그인해 담벼락 제목을 입력하고 `새 담벼락 열기`를 선택합니다.
2. 화면에 표시된 참여코드 또는 `학생 링크 복사`로 학생을 안내합니다.
3. 학생은 출석 번호를 먼저 입력한 뒤, 비어 있는 색 닉네임을 한 번 눌러 입장합니다.
4. 작성 단계에서 학생은 짧은 글과 이모지로 최대 3장의 포스트잇을 붙입니다.
5. 질문 단계에서는 모든 포스트잇이 같은 노란색으로 표시됩니다. 학생은 글과 질문 내용만 보고, 최대 5개의 익명 질문을 남깁니다.
6. 발표 단계에서 교사는 질문 수·최근 등록·오래된 등록 순으로 정렬하고, 포스트잇별 또는 전체 색 공개를 제어합니다.

## 교사용 기능

- 새 담벼락·참여코드 생성 및 학생 링크 QR 코드 표시
- 작성 → 전체 공개·질문 → 발표 단계 전환 (현재 단계는 버튼에 "현재 단계" 표시로 확인 가능)
- 질문 수 많은 순 / 최근 올린 순서 / 늦게 올린 순서 정렬
- 포스트잇 개별 색 공개·닫기, 전체 열기·닫기
- 포스트잇 발표 시 화면 전체에 큰 글씨로 자동 표시(발표 스포트라이트). 뒷자리에서도 보이도록 화면 너비에 맞춰 글자가 커지며, 교사 화면에서만 가+/가− 로 더 키우거나 접을 수 있음(학생 화면에는 영향 없음)
- 활동 타이머: 분 단위로 시작하면 모든 화면에 남은 시간이 표시되고, 0이 되면 소리·색 변화로 알려줌(단계 자동 전환은 하지 않음)
- 출석 번호 표시 켜기·끄기 (교사 화면 전용)
- 활동 기록 JSON 내려받기
- 선택 사항: 교사 컴퓨터에서만 실행하는 로컬 AI 도우미 연결 및 실시간 활동 요약

## 로컬 AI 도우미 (선택 사항)

실시간 AI 기능은 Firebase나 GitHub에 API 키를 저장하지 않습니다. 교사 컴퓨터에서만 작은 도우미를 실행하고, 키는 실행 중인 메모리에만 둡니다.

1. 교사 컴퓨터에서 이 저장소 폴더의 `AI-도우미-시작.cmd`를 두 번 클릭하거나, 터미널에서 `node ai-helper.js`를 실행합니다. 컴퓨터를 다시 켠 뒤에는 이 과정을 다시 해야 합니다.
2. 브라우저에서 <http://127.0.0.1:8787>을 열어 Upstage API 키와 모델 이름(기본값: `solar-pro3`)을 입력한 뒤 연결을 테스트합니다.
3. 교사 로그인 상태의 담벼락에서 `연결 새로고침`을 누릅니다.
4. `실시간 활동 요약`을 선택하면 출석번호·색 닉네임·Firebase UID를 제외한 포스트잇과 질문 텍스트만 AI 도우미로 전달됩니다.

키는 GitHub, Firebase Realtime Database, 브라우저 저장소에 기록하지 않습니다. 수업이 끝나면 AI 도우미 창을 닫거나 실행 중인 터미널에서 `Ctrl+C`를 누르면 메모리의 키가 사라집니다. Upstage API 비용은 별도로 발생할 수 있습니다.

## 학생 화면 원칙

- 실제 이름 대신 색 이름만 사용합니다.
- 출석 번호는 교사 기록에만 저장되며 친구에게 보이지 않습니다.
- 출석 번호 입력 전에는 색 선택이 비활성화됩니다.
- 아이패드에서 숫자 키패드가 열리며, 입력 중인 번호는 화면 갱신에도 유지됩니다.

## Firebase 설정

1. Firebase Console에서 웹 앱을 만듭니다.
2. Authentication에서 `익명`과 교사용 `이메일/비밀번호` 로그인을 활성화합니다.
3. Realtime Database를 만들고 [`database.rules.json`](database.rules.json)의 내용을 규칙 탭에 붙여 넣어 게시합니다.
4. [`firebase-config.example.js`](firebase-config.example.js)를 복사해 `firebase-config.js`로 이름을 바꾸고 Firebase 웹 설정값을 넣습니다.
5. [`app.js`](app.js)의 `TEACHER_UID`를 교사 Firebase 계정 UID로 바꿉니다.
6. GitHub Pages에서 기본 브랜치의 루트 폴더를 배포 원본으로 지정합니다.

> Firebase 웹 설정값은 웹앱에 노출되는 값입니다. 실제 보호는 Realtime Database 규칙과 교사 UID 검사로 처리합니다.

## 교실 사용 전 점검

- 교사 계정으로 로그인과 새 담벼락 생성이 되는지 확인합니다.
- 학생용 링크를 아이패드에서 열어 출석 번호 입력과 색 선택을 확인합니다.
- 교사 화면에서 질문 단계와 발표 단계 전환을 한 번씩 시험합니다.
- 프로젝터 공유 전에는 `출석 번호 보이기`가 꺼져 있는지 확인합니다.

## 개인정보와 안전

- 학생에게 이름·연락처 등 개인정보를 쓰지 않도록 안내합니다.
- 개인 경험 공개는 선택이며, 놀림·평가·무시는 허용하지 않습니다.
- 교사는 포스트잇과 질문을 검토하고 필요 시 Firebase Console에서 삭제할 수 있습니다.
- 활동이 끝난 뒤에는 Firebase Console에서 해당 활동 데이터와 익명 계정을 정리할 수 있습니다.

## 디자인

- A2z 웹폰트를 사용합니다.
- 데스크톱, 아이패드, 휴대폰 화면 폭에 맞게 포스트잇 열 수와 제어 패널이 바뀝니다.
